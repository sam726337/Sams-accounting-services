Product facts

Clear answers about Sams Accounting Desktop

Practical details for evaluating the Windows workflow before installation.

What does Sams Accounting Desktop automate?
It converts supported bank and Excel data into reviewable accounting entries, reconciles GST purchase records, generates sales entries, and sends verified vouchers to Tally Prime.
Which input files are supported?
The current workflows accept selectable bank statement PDFs, Excel bank rows, GST purchase Excel files, and structured Excel data for sales entries.
How does it connect to Tally Prime?
The desktop app connects to the Tally HTTP server on the local computer. The default connection is localhost on port 9000, with the required Tally company kept open.
Where is accounting data processed?
Accounting files are processed in the Windows desktop workflow, and Tally posting uses the local Tally connection rather than a remote accounting database.
Can entries be reviewed before posting?
Yes. Parsed transactions appear in a voucher preview where dates, amounts, voucher types, bank ledgers, opposite ledgers, and narration can be checked before posting.
Which operating system is supported?
Version 1.0.2 is distributed as a Windows installer. The current download is SamsAccountingSetup-1.0.2.exe.
